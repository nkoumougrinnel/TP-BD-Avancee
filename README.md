# 🎓 TP Bases de Données Avancées - Groupe 7

Ce dépôt centralise l'ensemble des travaux réalisés pour le module de Bases de Données Avancées. Il contient l'infrastructure de déploiement ainsi que les rendus des trois projets pratiques.

## 📁 Structure du Projet

- **`db-environment/`** : L'infrastructure Docker. Contient le `docker-compose.yml` pour lancer toutes les bases de données et le `README.md` avec les accès.
- **`TP1/`** : Administration PostgreSQL, Sécurité (Rôles/Privilèges) et Recherche Sémantique avec `pgvector`.
- **`TP2/`** : Exploration et manipulation des bases de données NoSQL (MongoDB, Redis, Cassandra, Neo4j).
- **`TP3/`** : Analyse de données et statistiques avec RStudio.

## 🚀 Installation Rapide

1. **Lancer les bases de données** :
   ```bash
   cd "db-environment"
   docker compose up -d
   ```
2. **Accès** :
   Consultez le fichier `db-environment/README.md` pour obtenir les ports, utilisateurs et mots de passe.
